## 🤖 Como as Skills Funcionam

Cada skill é composta por um arquivo `SKILL.md` com instruções padronizadas que orientam o desenvolvedor ou o agente de IA a manter um padrão sênior de implementação:

1. **Gatilho de Uso (`Quando usar`)**: Momento exato em que a skill deve ser consultada.
2. **Princípios Inegociáveis**: Regras arquiteturais e visuais fundamentais.
3. **Diretrizes Técnicas e Exemplos Práticos**: Código de referência, classes Tailwind e padrões React.
4. **Definition of Done (DoD)**: Critérios que comprovam que a entrega atingiu o padrão de qualidade exigido.
