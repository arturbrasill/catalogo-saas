# Skill — Backend Sheets

## Quando usar
Sempre que alterar Apps Script, estrutura das planilhas ou contrato REST.

## Princípios
- Sheets é persistência, não lógica de apresentação.
- Validar entrada.
- LockService em escrita.
- IDs gerados no servidor.
- Soft delete.
- Não expor secrets.
- JSON de variações deve ser validado.
- Respostas uniformes.

## Definition of Done
API executável, contratos documentados e testes relevantes passando.
