# PROTOCOLO DE EXECUÇÃO AUTÔNOMA

Use este arquivo junto ao prompt master.

## Antes de codar

- inspecione o projeto;
- descubra package manager;
- verifique Node;
- verifique testes;
- verifique Git;
- faça backup lógico do estado atual.

## Durante

Para cada tarefa:

1. escreva um plano curto;
2. implemente;
3. rode typecheck;
4. rode lint;
5. rode testes;
6. corrija falhas;
7. documente mudanças.

## Não fazer

- não criar arquivos duplicados sem necessidade;
- não substituir arquitetura existente sem avaliar;
- não usar `any` indiscriminadamente;
- não desabilitar TypeScript para esconder erro;
- não remover testes para fazer build passar;
- não colocar credenciais em código;
- não declarar conclusão sem verificar.

## Ao terminar

Mostrar:

- arquivos criados;
- arquivos alterados;
- comandos executados;
- testes;
- pendências;
- próximos passos.
